# Python 作品集：タスク管理RPG & マリオ風ゲーム

Python で作った 2 つのアプリをここに置いているため、概要を紹介します。

| 作品 | ファイル | 使用ライブラリ | 概要 |
|---|---|---|---|
| タスク管理RPG | `main.py` | PySide6 | タスクを完了すると経験値がたまり、レベルが上がるデスクトップアプリ |
| マリオ風ゲーム | `main.py` | pygame | 横スクロールのアクションゲーム |

> 2つとも `main.py` という名前で動かしたい場合は、別々のフォルダに分けて配置してください。

---

## 1. タスク管理RPG（`main.py`）

### 特徴
- タスクの追加・完了・削除（内容 / 日付 / 重要度★1〜5 / 獲得EXP）
- 4つのタブで表示を切り替え
  - 📅 今日：期限が今日以前、またはアクティブのタスク
  - 📋 全部：未完了のすべてのタスク
  - 🗃 完了：完了したタスク
  - ⚡ アクティブ：「アクティブ」にチェックしたタスク
- 🔁 毎日のルーティン：1日1回、日付が変わるとリセットされる習慣タスク
- レベルシステム：完了したタスクとその日のルーティンのEXP合計から計算（50 EXPでレベルアップ）
- データは `tasks.json` に自動保存

### 実装機能
- 日付表示：今日の日付と曜日をヘッダーに表示し、60秒ごとに自動更新
- 日付選択：手入力の手間を減らすため、カレンダーから選択できるようにした
- タスク追加：内容が空のときは追加しない。EXPが未入力・数字以外の場合は5に自動設定
- 重要度選択：★1〜5をプルダウンから選べるようにした
- 表示の振り分け：今日 / 全部 / 完了 / アクティブの4タブに自動で振り分け
- 完了チェック：チェックでEXPを獲得し、完了日を記録して「完了」タブへ移動
- アクティブ指定：期限が先のタスクでも、チェックすれば「今日」タブに表示
- タスク削除：削除ボタンで1件ずつ削除
- ルーティン：毎日使う習慣タスクを登録でき、日付が変わると未完了に戻る
- レベル計算：完了タスク＋今日のルーティンのEXP合計から、50 EXPごとにレベルアップ
- レベルアップ演出：レベルが上がると「レベルアップ！」を3秒間表示
- 自動保存・読込：変更のたびに `tasks.json` へ保存し、起動時に復元（旧形式のデータにも対応）

### 使い方
```bash
pip install PySide6
python main.py
```

1. 上部の入力欄にタスク内容・日付・重要度・EXPを入力して「追加」（EXP未入力は5）
2. 「完了」にチェックするとEXPを獲得
3. 右側でルーティンを追加し、毎日チェック

## 2. マリオ風ゲーム（`main.py`）

### 特徴
- 横スクロールのステージ（20px のタイルマップ、全64タイル幅）
- 敵「クリボーのような青い敵」を踏むと倒せる。横から当たるとゲームオーバー
- ゲームオーバー後、2秒待って自動でリスタート
- BGMをループ再生

### 操作方法
| キー | 動作 |
|---|---|
| ← / → | 左右移動（加速・減速あり） |
| Space | ジャンプ |

### 実装機能
- パス管理：`Path(__file__)` を基準にし、どのフォルダから実行しても素材を読み込めるようにした
- BGM再生：ゲーム開始と同時にBGMをループ再生
- マップ描画：数字の二次元リスト（0=空、1=壁、2=ブロック）でステージを定義し、タイルを並べて描画
- スクロール：マリオが画面の途中（x=120）を超えると、マリオを固定してマップ側を動かす
- 左右移動：加速度（0.25）と最高速度（5）を設定し、離すと徐々に減速
- ジャンプ：地面にいるときだけSpaceでジャンプ。重力で落下
- 当たり判定：周囲のタイルとの衝突を判定し、壁や床にめり込まないよう位置を補正
- 歩行アニメ：2枚の画像を切り替え、向きに応じて左右反転
- クリボーの移動：左右に歩き、壁や端に当たると反転
- 踏みつけ判定：上から当たれば敵を倒してマリオが跳ね返り、横から当たればマリオがやられる
- 敵の消滅：踏まれたクリボーは潰れた画像を30フレーム表示してから消える
- ゲームオーバー演出：やられると専用画像で跳ね上がってから画面外へ落下
- リスタート：2秒待って自動で最初からやり直し
- 状態管理：`Enum` で通常 / やられ中 / 死亡 / 踏みつけ中を区別
- フレームレート：30FPSに固定

### 使い方
```bash
pip install pygame
python main.py
```
